# T1595.003 — Wordlist Scanning

A támadó szólisták (wordlist) segítségével iteratívan próbálja feltérképezni a célpont infrastruktúráját - nem érvényes hitelesítési adatokat keres, hanem rejtett tartalmakat és felületeket. A szólista generikus, széles körben használt fájlneveket és könyvtárneveket tartalmazhat, de lehet célpont-specifikus is, amit más felderítési technikák során gyűjtött adatokból állít össze.
Két fő alkalmazási területe:
- **Webes tartalom felderítése:** weboldalak rejtett könyvtárainak, régi vagy nem linkelt oldalainak, adminisztrációs felületeinek megtalálása (Gobuster, Dirb, DirBuster)
-  **Cloud storage felderítés:** publikus vagy privát cloud tárolók (S3 bucket, GCP bucket) azonosítása célpont-specifikus szólistákkal, mivel ezek globálisan egyedi neveket használnak

---
## Mitigáció

Minden hozzáférés letiltása olyan rendszerhez, erőforráshoz és infrastruktúrához, amelynek nincs kifejezetten külső elérhetősége.
Ez a technika nem könnyen mérsékelhető megelőző ellenőrzésekkel, mivel a vállalati védelmi és ellenőrzési intézkedéseken kívüli viselkedésen alapul.

## Detekciós stratégia

### Szükséges telemetria

| Adatforrás                       | Típus           | Megjegyzés                                                                                                  |
| -------------------------------- | --------------- | ----------------------------------------------------------------------------------------------------------- |
| IDS/IPS log                      | Network Traffic | Wordlist scanner eszközök szignatúra-alapú felismerése                                                      |
| Web szerver / Proxy log (Access) | Network Traffic | Automatizált, rendszeres HTTP probe kérések, a sérülékenységvizsgálatot végző eszköz user-agent stringjével |
| Cloud audit log                  | Cloud Storage   | S3 / GCP bucket hozzáférési kísérletek, nem létező bucket névfeloldások                                     |
### Detekciós lehetőség

Mivel a Wordlist Scanning az alkalmazás rétegben zajlik, ezért itt a webszerver access log a legértékesebb telemetria forrás.

Felismerhető minták:
- Rövid időn belül nagyszámú HTTP 404 válasz egyetlen forrás IP-ről — a szólista nem létező útvonalakat is tartalmaz, ezért a 404 arány jellemzően magas
- Az eszközök alapértelmezett user-agent stringje gyakran nem kerül módosításra (pl. `gobuster/3.1.0`, `DirBuster-1.0`)
- Szabályos, alfabetikus vagy szótár-sorrendű URL kérési minta — emberi böngészési viselkedéstől jól elkülöníthető
- Cloud környezetben: nem létező bucket nevekre irányuló DNS feloldási kísérletek nagy száma

A védelmet itt nem SIEM oldalon kell megoldani — a webszerver és a WAF (Web Application Firewall) rate limiting és anomália-alapú konfigurációja az elsődleges védelmi vonal. A WAF képes felismerni és blokkolni az automatizált scanning forgalmat user-agent és kérési minta alapján.
